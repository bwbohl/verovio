# Verovio Toolkit Java

This module provides the Java JNI bindings for [Verovio](https://www.verovio.org),
a fast, portable, and lightweight music notation engraving library.

Currently it’s included from a fork to improve the provided Maven POM but all the sources are identical to Verovio 6.1.1.
